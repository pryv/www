We are happy to announce that Exoscale, the Swiss cloud provider, now supports Open Pryv.io with a free usage credit on its infrastructure. A warm thank you to the Exoscale team for backing an open-source project dedicated to personal data and consent management.

Open Pryv.io on the Exoscale Marketplace

Open Pryv.io is available as a ready-made template on the Exoscale Marketplace. You launch an instance with a single setting, your server's host name, and a few minutes later it runs Open Pryv.io with its own HTTPS certificate, ready to register users. The template uses the official Open Pryv.io Docker image on Ubuntu 24.04 LTS and is available in every Exoscale zone, in Switzerland, Germany, Austria, Bulgaria and Croatia.

Every template is built and tested end to end on Exoscale before it is published: launch from the Marketplace settings, certificate issuance, user registration, sign-in from a third-party app, restart and reboot. The setup guide is here: Open Pryv.io on Exoscale.

What else we run on Exoscale

  • The European core of pryv.me, our public demonstration platform, is moving to Exoscale's Geneva zone. Each Pryv.io core is fully independent and keeps its users' data where it runs, so the platform offers a Swiss hosting option next to its US one.
  • A release canary: every Open Pryv.io release is deployed and tested on an Exoscale instance before it reaches pryv.me.
  • Build and test machines for the Marketplace template and for tests that need a server reachable from the internet.

Why it fits

Open Pryv.io is Swiss-made software for keeping personal data under control: where it is stored, who may access it, and for what purpose. Running our reference instances with a European provider headquartered in Switzerland, with the choice of the country where each server runs, puts that principle into practice for our own deployments too.

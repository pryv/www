We are happy to announce that Exoscale, the Swiss cloud provider, now supports Open Pryv.io on its infrastructure. A warm thank you to the Exoscale team for backing an open-source project dedicated to personal data and consent management.

Open Pryv.io on the Exoscale Marketplace

Open Pryv.io is now available as a ready-made template on the Exoscale Marketplace.

Launching an instance requires just a single configuration setting: your server's hostname.

Within minutes, the system deploys Open Pryv.io with an automated HTTPS certificate, fully prepared to register users. Built on the official Open Pryv.io Docker image running on Ubuntu 24.04 LTS, the template is available across all Exoscale zones: Switzerland, Germany, Austria, Bulgaria, and Croatia.

To ensure production reliability, every template is built and tested end-to-end on Exoscale before release:

  • Automated deployment using Marketplace settings
  • SSL/TLS certificate issuance
  • User registration and authentication flows via third-party apps
  • System reboot and service recovery resilience

For step-by-step instructions, visit the Open Pryv.io Setup Guide.

What we run on Exoscale

Beyond the marketplace image, Exoscale powers:

  • European Demonstration Platform: The European core of pryv.me is hosted in Exoscale's Geneva zone. Because each Pryv.io core operates independently and stores user data locally, users have a sovereign Swiss hosting option alongside our US instance.
  • Release Canary: Every Open Pryv.io release is deployed and validated on an Exoscale staging instance before rolling out to production.
  • Automated CI/CD: Build and testing instances for Marketplace template and tests requiring publicly accessible network endpoints.

Why This Partnership Fits

Open Pryv.io is Swiss-made software for keeping personal data under control: where it is stored, who may access it, and for what purpose.

Partnering with Exoscale, a European provider headquartered in Switzerland with localised regional data zones, allows us to practice what we preach. We can guarantee data sovereignty and geographic boundaries directly at the infrastructure level.
